02 / About

I work on my own, under the studio name NovaEdge. Most of what is on this page started as a small problem I wanted solved: notes that write themselves up, a resume that gets honest feedback, a shop that tells customers when a product is back.

I build the whole thing myself: the interface, the backend, the database and the deployment. That keeps the loop short. I can notice something feels wrong in the morning and have a fix live by the afternoon.

Some of these projects are live, some are still concepts, and a few are experiments that taught me more than they earned. I have labelled each one so you know which is which.

04 / My approach

(it’s never this tidy in real life)
01

Find the problem

Start with who is stuck and why. If I cannot say it in one sentence, I am not ready to build it.

02

Design a solution

Sketch the smallest version that would be useful, and decide what to leave out.

03

Build it

A working version first, in real code, deployed early so that it can actually be used.

04

Test it

Use it, break it, watch someone else try it. Fix whatever confuses people.

05

Improve it

Keep what works, cut what does not, and decide if it deserves to keep going.
